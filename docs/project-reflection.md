# Project Reflection and Future Improvements

## Reflection

The project demonstrated how threat modelling, secure coding and automated security testing can be integrated into the software development lifecycle.

Four vulnerabilities were demonstrated, remediated and re-tested. The CI/CD pipeline also integrated SAST, SCA, secrets scanning and container security checks.

The project provided practical experience in identifying application security weaknesses and applying security controls during development.

## Limitations

Some dependency vulnerabilities could not be completely removed without potentially introducing compatibility or breaking changes.

The project also focused mainly on the implemented security controls and did not include a complete dynamic application security testing process.

## Future Improvements

Future improvements could include:

- Dynamic Application Security Testing using OWASP ZAP
- Additional automated security tests
- Further dependency remediation
- Stronger container hardening
- Additional security monitoring and reporting

These improvements could provide broader security coverage in future development cycles.
